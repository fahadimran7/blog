---
title: "Do you actually read the code anymore?"
date: 2026-10-15
description: "Raw thoughts on not reading the code AI writes for me."
tags: ["ai", "programming"]
---

I've seen a lot of videos on this from people like [Theo](https://x.com/theo) and [DHH](https://x.com/dhh), and from all the hype bros and 10x developers out there.

A lot of people are saying they don't actually read the code anymore. If you want to move fast with AI and you keep reading every line, there's no point. You can't unlock the productivity gains AI promises. And more and more, my own experience has been going the same way.

I'm not saying I'm 10x more productive or building really cool shit. But in my day-to-day work I've started reading the code less and less. Claude Opus 5.5 was a big turning point for me (man, is it good).

But even before that, this had been my workflow for quite some time. I start a conversation with the agent, kind of like I would with a coworker. I talk through the idea and the edge cases, ask for feedback, and clarify the details that are in my head. Once I'm at a place where the implementation is clear, I ask it to start working. It's not plan mode, but it's basically planning with the agent. I read the output when we are discussing, but I don't really review the code. As weird as that might sound, I'm not alone in that. I've talked to colleagues working at other companies, and they feel the same way.

On my personal side projects, I'm less worried about code quality in general than I would be with a really critical piece of software. But even at work, I've shipped features and bug fixes without reading much of the code, and there weren't any issues to speak of. It went mostly fine, which is genuinely a shock given where we were six months to a year ago.

I know, this does sound very reckless, and I do believe there should be guardrails. Good test coverage, a CI pipeline that runs those tests on every PR and blocks the merge when something breaks, and a review agent going over the changes. A lot of this is automated now, and having another agent review the code does help. It points out real issues. I've done it, and I see other people doing it as well. But the fact remains that humans aren't really reading the code anymore. Well at least most of us aren't.

And yes, it is making us dumber. We're offloading more and more of our thinking, reasoning, and our cognitive abilities to these agents. That's the sad reality of where we are right now.

I'm not sure how long we can keep doing this, or if there'll come a time when we will focus on the code again. But for now, as the models keep getting better, I think it's only going to get worse.
